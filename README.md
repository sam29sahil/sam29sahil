### 🛡️ CyberDefense XDR — AI-Augmented SOC / XDR Platform

**XDR • SOC • SIEM • VAPT • Suricata • TShark • Flask • PostgreSQL • Docker**

Built an enterprise-style Extended Detection & Response platform with **23 Flask blueprints and 31 PostgreSQL models**, unifying SIEM log ingestion, Suricata network IDS, TShark packet analysis, and a multi-engine vulnerability scanner using Nmap, Nikto, Nuclei, WhatWeb, and testssl.sh.

- Threat correlation with **0–100 risk scoring**
- Federated threat hunting across **10 database tables**
- **10 human-approved SOAR playbooks**
- Enterprise RBAC with **5 roles and 38 permissions**
- Security hardening covering OWASP headers, strict CSP, shell/CSV injection defenses, account lockout, and session hardening
- Dockerized deployment with PostgreSQL and production Gunicorn configuration

🔗 **[View Repository](https://github.com/sam29sahil/CyberDefense-XDR)**
