## 🚀 Featured Projects

### ☁️ CloudShield Enterprise
**Cloud Security • Flask • Azure • Security Assessment**

Enterprise cybersecurity platform combining website security assessment with **Microsoft Azure cloud security scanning**. Includes HTTP headers, SSL/TLS, DNS, WHOIS and open-port assessment, centralized findings, severity scoring, risk assessment, authentication, dashboard tracking and automated reporting.

🔗 [View Repository](https://github.com/sam29sahil/CloudShield-Enterprise)

---

### ⚙️ DevSecOps Platform
**DevSecOps • CI/CD • SAST • Trivy • Azure**

Self-hosted **9-stage security-gated CI/CD platform** covering checkout, dependency inspection, secret detection, SAST, quality gates, Docker build, Trivy vulnerability scanning, Azure Container Registry push and Azure Container Apps deployment.

Includes a dependency-free regex-based SAST engine plus a **React + Vite dashboard** backed by a Flask REST API.

🔗 [View Repository](https://github.com/sam29sahil/DevSecOps-Platform)

---

### 🚀 CloudDeploy Pro Enterprise
**Cloud • Docker • Flask • Container Management**

Flask and Docker-based cloud deployment management platform with centralized project, deployment and container monitoring dashboards.

Features container lifecycle management, logs, real-time CPU/memory/disk/network monitoring and PDF/CSV reporting.

🔗 [View Repository](https://github.com/sam29sahil/Clouddeploy_pro)
